# Rongdhonu Shop (রংধনু ডিজিটাল স্টুডিও) - Windows Desktop Edition

## 1. Direct Execution on Windows 10 & 11
You can run the application directly without installing:
1. Open the folder `dist-installers/win-unpacked/`
2. Double click **`Rongdhonu Shop.exe`**

## 2. Generating the NSIS Windows Installer (`Rongdhonu-Shop-Setup.exe`)
On a Windows computer with Node.js installed:
```bash
npm install
npm run dist:win
```
This will compile the installer and save it to `dist-installers/Rongdhonu-Shop-Setup.exe`.
